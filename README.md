# Directive insights preview

A standalone, iOS-style presentation of saved QA outputs for Financial Resilience, Talent Development and Regional Development.

- Original baseline using unchanged Agent prompts, plus V7–V10 Executive Summary experiments.
- English/Arabic, light/dark, desktop comparison and responsive mobile view.
- V7–V10 regenerate only Executive Summary and Arabic; eight other sections stay fixed across those experiments. The original baseline is an earlier full generation, so its sections and summary inputs can differ. This is not an identical-input baseline-versus-experiment test.
- Review notes remain available. The outputs are experimental QA material, not verified live project status.

Open `index.html` directly or use the published GitHub Pages site. No server, API, login, model key or build step is required. The page makes no model calls or external asset requests. All text is rendered from a narrowly exported saved-results dataset; raw QA inputs, credentials and SG profile files are excluded.
